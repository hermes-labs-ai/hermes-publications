# Distribution copy assets

This folder contains **prepared discovery copy**, not distribution state.

A discovery copy kit gives an agent accurate, reusable language for a specific
owned Hermes surface without requiring the agent to summarize each paper again.
It may contain:

- a short paper-discovery snippet;
- the intended reader or use-case;
- a truthful call to action;
- a cross-paper `Read next` link;
- candidate owned-surface placements.

## How agents should use a kit

1. Read the newest snapshot linked from [`../README.md`](../README.md).
2. Confirm the exact target surface and paper identity against
   [`../../publications.json`](../../publications.json).
3. Take only the copy components needed for that target; do not deploy every
   asset merely because it is available.
4. Keep destination-specific edits, review, authorization, deployment, and
   readback in the appropriate repository or operational workspace.

## What a kit is not

A kit is not:

- the canonical paper index or a replacement for the Zenodo record;
- a current distribution-status snapshot;
- evidence that a channel, page, or repository is live;
- approval to edit, push, deploy, post, email, submit, or publish;
- evidence that the copy will increase traffic, downloads, citations, or use.

Every asset must state its preparation status and public effect. Historical
kits remain leads; newer evidence or destination-specific copy may supersede
them without silently rewriting the old file.
